# LATO Documentation

Usage and testing documentation for the LATO assessment platform. (This folder
is about **using and testing** LATO, not deploying it.)

| Document | Purpose |
|----------|---------|
| [How to Use](./HOW_TO_USE.md) | Task‑oriented quick start for each role (expert, taker, company buyer, admin). |
| [User Manual](./USER_MANUAL.md) | Complete reference for every screen, setting, and workflow. |
| [QA Test Checklist](./qa/QA_Test_Checklist.xlsx) | Internal quality‑assurance test cases (65) with Status/Priority tracking and a summary tab. |
| [UAT Test Checklist](./qa/UAT_Test_Checklist.xlsx) | User‑acceptance scenarios (16) with Accepted/Rejected tracking and a summary tab. |

The spreadsheets' **Summary** tabs use live `COUNTIF` formulas that recalculate
automatically when opened in Excel or Google Sheets.
